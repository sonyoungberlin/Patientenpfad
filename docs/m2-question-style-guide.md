# M2-Fragen: Style Guide

M2-Fragen zeigen den Klärungsstand je Checkpoint. Sie sind keine Wissensfragen, keine
Regelabfragen und keine Formulare. Ihr einziger Zweck: sichtbar machen, ob ein Punkt geklärt
ist oder noch offen steht — sofort beantwortbar mit **Ja / Nein / Unklar**.

---

## Grundregeln

### 1. Konkrete Rolle nennen

Jede Frage benennt, wer handelt oder wer etwas festgelegt hat.
Passivkonstruktionen ohne Handelnden sind nicht erlaubt.

```
Nicht: „Ist intern festgelegt, wer die Meldung erstellt?"
Besser: „Hat die Praxisleitung festgelegt, wer die Meldung an das Gesundheitsamt erstellt?"
```

### 2. Kein „intern" ohne Subjekt

„Intern festgelegt", „intern abgestimmt", „intern entschieden" sind nur erlaubt, wenn das
Subjekt im selben Satz steht.

```
Nicht: „Ist intern entschieden, wie auf die KV-Beanstandung reagiert wird?"
Besser: „Hat die Praxisleitung entschieden, wie auf die KV-Beanstandung reagiert wird?"
```

### 3. Kein „bekannt, ob" als Einstieg

„Ist bekannt, ob X nötig ist?" fragt nach externem Wissen, nicht nach dem Klärungsstand.
Formulierung immer als Zustandsfrage mit konkreter Rolle.

```
Nicht: „Ist bekannt, ob eine Meldepflicht gegenüber der KV besteht?"
Besser: „Hat die Praxisleitung geprüft, ob für diesen Zeitraum eine Meldepflicht gegenüber der KV Berlin besteht?"
```

### 4. Keine „betroffenen Personen", wenn eine Rolle bekannt ist

„Betroffene Personen" oder „betroffene Mitarbeitende" sind nur dann zulässig, wenn die
Personengruppe im jeweiligen Fall wirklich variiert. Wenn es um Ärzte, MFA, Patienten oder
die Praxisleitung geht, muss die Rolle direkt genannt werden.

```
Nicht: „Ist die Benachrichtigung der betroffenen Personen eingeleitet?"
Besser: „Ist die Benachrichtigung der betroffenen Patienten eingeleitet?"
```

### 5. Keine Regelprüfung als Wissensfrage

Fragen wie „Ist bekannt, ob Fachkundenachweise erforderlich sind?" fragen nicht nach dem
Klärungsstand, sondern danach, ob jemand eine Regel kennt. Das ist keine M2-Frage.
Stattdessen: Wurde der Punkt aktiv geklärt?

```
Nicht: „Ist bekannt, ob Fachkundenachweise für dieses Gerät erforderlich sind?"
Besser: „Hat die Praxisleitung geprüft, ob für dieses Gerät Fachkundenachweise vorgeschrieben sind?"
```

### 6. Kein „zuständig" ohne Benennung

„Die zuständige Person" oder „eine zuständige Stelle" benennen nichts Konkretes. Entweder
die Rolle direkt nennen oder die Institution angeben.

```
Nicht: „Hat die zuständige Person die Antwort an die KV freigegeben?"
Besser: „Hat die Praxisleitung die Antwort an die KV freigegeben?"
```

### 7. Kein direktes W-Fragewort am Satzanfang

Fragen dürfen nicht mit `Wer`, `Was`, `Wie`, `Wann`, `Wo` oder `Warum` beginnen.
Eingebettet sind W-Fragen erlaubt: „Ist festgelegt, wer…"

### 8. Kein „oder" außerhalb von Klammern

`… oder …` im Hauptsatz erzeugt Entscheidungsambiguität und verhindert eine klare Ja/Nein-
Antwort. Ausnahmen: Gendering (`Arzt oder Ärztin`, `Patientinnen oder Patienten`) und
erklärende Klammern (`(z. B. Anstellungsgenehmigung oder Anzeige)`).

### 9. Verbotene Begriffe

Diese Begriffe sind in M2-Fragen grundsätzlich nicht erlaubt:

| Verboten | Grund |
|---|---|
| `sichergestellt` | Passiv ohne Handelnden |
| `regelkonform` | Governance-Sprache |
| `belastbar` | Governance-Sprache |
| `ableitbar` | Governance-Sprache |
| `maßgeblich` | Governance-Sprache |
| `Compliance` | Governance-Sprache |
| `wurde bewertet` / `wurden bewertet` | Passiv ohne Handelnden |
| `Entscheidungshilfe` | Nicht Zweck einer M2-Frage |
| `Empfehlung` | Nicht Zweck einer M2-Frage |

## Rollenliste

Wenn eine Handlung einer Person oder Institution zugeordnet wird, muss eine der folgenden
Bezeichnungen verwendet werden — oder eine gleichwertige, ebenso konkrete Angabe.

| Rolle | Wann verwenden |
|---|---|
| **Praxisleitung** | Entscheidungen, Freigaben, interne Festlegungen |
| **Arzt / Ärztin** | Medizinische Beurteilung, Fallverantwortung |
| **behandelnder Arzt** | Konkret fallverantwortlicher Arzt |
| **MFA** | Organisatorische Aufgaben, Verwaltung |
| **Patient / Patientin** | Informationspflichten gegenüber Patientinnen und Patienten |
| **Vertretungsarzt** | Vertretungsvereinbarungen, Abrechnungszuordnung |
| **KV Berlin** | Meldepflichten, Genehmigungen, Abrechnung |
| **Ärztekammer Berlin** | Registrierung, Fortbildungspunkte, Ausbildungsverträge |
| **Lohnbüro** | Anmeldung, Abmeldung, Gehaltsabrechnungen |
| **Steuerberater** | Honorar- und Abrechnungsfragen mit steuerlichem Bezug |
| **Gesundheitsamt** | Meldepflichten nach IfSG |
| **Zulassungsausschuss Berlin** | Zulassungen, Anstellungsgenehmigungen |

Wenn keine dieser Rollen passt: explizit beschreiben, wer gemeint ist
(`„der externe IT-Dienstleister"`, `„die zuliefernde Praxis"`).
Niemals nur `„eine externe Stelle"` schreiben.

## Beispiele: schlecht → gut

### Beispiel 1 — Kein Subjekt

| | Text |
|---|---|
| **Nicht** | „Ist intern bekannt, um welche Art von KV-Vorgang es sich handelt?" |
| **Besser** | „Hat die Praxisleitung den KV-Vorgang als Abrechnung, Plausibilität oder Regress eingeordnet?" |
| **Grund** | „Intern bekannt" benennt niemanden. Die Praxisleitung ist der Handelnde. |

---

### Beispiel 2 — „zuständig" ohne Rollenbenennung

| | Text |
|---|---|
| **Nicht** | „Hat die zuständige Person in der Praxis die Antwort an die KV freigegeben?" |
| **Besser** | „Hat die Praxisleitung die Antwort an die KV Berlin freigegeben?" |
| **Grund** | „Zuständige Person" ist keine beantwortbare Information. |

---

### Beispiel 3 — Regelprüfung als Wissensfrage

| | Text |
|---|---|
| **Nicht** | „Ist bekannt, ob am Standort ein zulassungsfähiger Sitz für das Fachgebiet verfügbar ist?" |
| **Besser** | „Hat die Praxisleitung beim Zulassungsausschuss Berlin geprüft, ob am Standort ein freier Sitz für das Fachgebiet verfügbar ist?" |
| **Grund** | Die erste Frage fragt nach Wissen, nicht nach dem Klärungsstand. |

---

### Beispiel 4 — „betroffene Personen" statt konkreter Rolle

| | Text |
|---|---|
| **Nicht** | „Sind die neuen Arbeitszeiten mit den betroffenen Mitarbeitenden abgestimmt?" |
| **Besser** | „Hat die Praxisleitung die neuen Sprechzeiten mit allen betroffenen MFA und Ärzten besprochen?" |
| **Grund** | „Betroffene Mitarbeitende" ist so vage, dass die Frage nicht eindeutig mit Ja/Nein beantwortet werden kann. |

---

### Beispiel 5 — „geregelt" ohne Subjekt

| | Text |
|---|---|
| **Nicht** | „Ist geregelt, wer die laufenden Patientenfälle in der Übergangsphase betreut?" |
| **Besser** | „Hat die Praxisleitung festgelegt, welcher Arzt die laufenden Patientenfälle bis zum Austrittsdatum betreut?" |
| **Grund** | „Geregelt" ohne Handelnden ist Passiv. Wer hat es geregelt? |

---

### Beispiel 6 — Kein „intern abgestimmt" ohne Subjekt

| | Text |
|---|---|
| **Nicht** | „Ist intern abgestimmt, welche Patienten über den Austritt informiert werden müssen?" |
| **Besser** | „Hat die Praxisleitung festgelegt, welche Patienten aktiv über den Austritt informiert werden?" |
| **Grund** | „Intern abgestimmt" verschweigt, wer die Entscheidung getroffen hat. |

---

### Beispiel 7 — Passiv bei „prüfen"

| | Text |
|---|---|
| **Nicht** | „Ist intern geprüft, ob die Vertragsbedingungen zum geplanten Einsatz passen?" |
| **Besser** | „Hat die Praxisleitung bestätigt, dass die Vertragsbedingungen zum geplanten Einsatz der MFA passen?" |
| **Grund** | „Intern geprüft" ohne Subjekt ist nicht beantwortbar. |

---

## Abgrenzung: Wann Aktivformulierungen nicht erzwungen werden sollen

Die Regeln 1 und 2 sollen sicherstellen, dass M2-Fragen klare Verantwortlichkeiten benennen.
Sie sind kein Auftrag, jede Zustandsfrage mechanisch in eine Aktivformulierung umzuschreiben.

### „Praxisleitung" nur bei echten Leitungsaufgaben

Die Rolle `Praxisleitung` ist angemessen bei:

- formellen Freigaben und Genehmigungen
- Zuständigkeitszuweisungen und Personalentscheidungen
- Compliance- und Rechtsverantwortung
- strategischen Organisationsentscheidungen (z. B. Systemumstellungen, Öffnungszeiten)

Die Rolle `Praxisleitung` ist **nicht** angemessen bei:

- kollektiv getragenen Organisationszuständen (z. B. Wissensstand im Team)
- delegierten operativen Abläufen (z. B. Schichtübergaben, Dienstplanaktualisierungen)
- technischen Statusfragen (z. B. „Ist das Zeiterfassungssystem aktualisiert?")
- Patientenkommunikation, die über die Praxis als Organisation erfolgt — nicht als persönlicher Leitungsakt

Wenn Patientenkommunikation als Organisationshandlung gemeint ist, steht `die Praxis` als Subjekt:

```
Nicht: „Hat die Praxisleitung Patientinnen und Patienten über Änderungen informiert?"
Besser: „Hat die Praxis Patientinnen und Patienten über Änderungen informiert?"
```

### „intern" bleibt zulässig bei kollektivem Wissensstand

„Intern" ist erlaubt, wenn:

- ein kollektiver Informationsstand im Team geprüft wird: „Sind alle Abwesenheiten im Team bekannt?"
- eine organisatorische Einigkeit ohne klaren Einzelakteur gemeint ist
- kein spezifischer Entscheidungsträger sinnvoll benennbar ist

„Intern" ist **nicht** erlaubt, wenn eine echte Verantwortungslücke verschleiert wird — z. B. wer eine strategische Entscheidung getroffen hat oder wer für eine Meldepflicht zuständig ist.

### Zustandsfragen sind ausdrücklich zulässig

Folgende Fragetypen müssen nicht aktiviert werden:

- **Technische Status-Checks:** „Ist der Dienstplan angepasst?", „Ist die Telefonansage aktualisiert?"
- **Vollständigkeitsprüfungen:** „Liegen alle Unterlagen vor?", „Sind alle offenen Punkte abgearbeitet?"
- **Existenzfragen:** „Gibt es ungeklärte operative Lücken?"
- **Teamwissen:** „Sind alle Mitarbeitenden informiert?", „Sind alle Abwesenheiten im Team bekannt?"

Diese Fragen prüfen Ergebnisse, nicht Prozesse. Das Ergebnis ist mit Ja/Nein beantwortbar — unabhängig davon, wer es herbeigeführt hat.

---

## Checkliste vor neuen M2-Fragen

Vor dem Eintragen einer neuen M2-Frage folgende Punkte prüfen:

- [ ] Ist eine konkrete Rolle (Praxisleitung, Arzt, MFA, …) im Satz genannt?
- [ ] Kann die Frage mit Ja, Nein oder Unklar beantwortet werden — ohne Rückfrage?
- [ ] Beginnt die Frage nicht mit einem W-Fragewort (`Wer`, `Was`, `Wie`, `Wann`, `Wo`, `Warum`)?
- [ ] Enthält die Frage kein „intern" ohne zugehöriges Subjekt?
- [ ] Enthält die Frage keinen Ausdruck aus der Verbotsliste (`sichergestellt`, `regelkonform`, `Compliance`, …)?
- [ ] Wird keine externe Regelkenntnis abgefragt (`bekannt, ob X nötig ist`)?
- [ ] Steht kein „zuständig" ohne Rollenbenennung im Satz?
- [ ] Enthält die Frage kein „oder" außerhalb von Klammern (außer Gendering)?
