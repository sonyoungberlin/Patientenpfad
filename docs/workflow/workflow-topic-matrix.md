# Fachmatrix: Workflow-Modul Musterprozesse

Letzte fachliche Überarbeitung: 2026-06-20

## 1. Rezept

| Bereich | MFA-Fragen | Arzt-Fragen |
|---|---|---|
| **Formale Angaben** | Ist das Präparat benannt? | Ist das Präparat mit Wirkstärke und Darreichungsform dokumentiert? |
| | Sind Wirkstärke, Packungsgröße/Menge und Dosierung angegeben? | Ist erkennbar, ob Akut- oder Dauermedikation vorliegt? |
| | Ist erkennbar, ob Akut- oder Dauermedikation? | Sind Kostenträger und Versichertenstatus erfasst? |
| | Sind Kostenträger und Versichertenstatus erfasst? | |
| | Ist das Ausstellungsdatum angegeben? | |
| **Entscheidungsgrundlage** | Liegt eine bekannte Diagnose oder Dauermedikation vor? | Ist die Indikation für das Präparat aus der Akte nachvollziehbar? |
| | Sind Hinweise auf Unverträglichkeiten oder Wechselwirkungen in der Akte erkennbar? | Ist die aktuelle Medikamentenliste im System erkennbar? |
| | | Gibt es Hinweise auf Kontraindikationen oder relevante Wechselwirkungen? |
| **Verlauf und Kontext** | Gibt es frühere Anfragen für dasselbe oder ähnliche Präparate? | Gibt es Verlaufshinweise, die für die Verordnung relevant sind? |
| | Gibt es Hinweise auf Dosisänderungen oder Therapieabbrüche? | Gibt es Hinweise auf besondere Rahmenbedingungen? z. B. Langzeittherapie, BtM-Pflicht. |
| | Wurde der Patient bereits zu Kontrolle, Untersuchung oder Befundvorlage aufgefordert? | Sind erforderliche Kontrollen oder Verlaufskontrollen dokumentiert? |
| | Gibt es offene Rückmeldungen oder ausstehende Befunde? | Liegen erforderliche Facharztbefunde vor? |
| | | Gibt es offene Anforderungen an den Patienten? z. B. Kontrolle, Labor, Befunde. |
| | | Ist dokumentiert, warum gegebenenfalls nur eine eingeschränkte Verordnung erfolgt? |
| **Weiteres Vorgehen** | Ist dokumentiert, ob Laborkontrolle oder Wiedervorstellung erforderlich ist? | Ist dokumentiert, ob und wann eine Kontrolle oder Folgeverordnung geplant ist? |
| | Ist ein nächster Schritt erkennbar? | |

**Typische Dokumentationsfehler**
- Fehlende Dosierung oder Packungsgröße
- Kein Hinweis auf Akut- vs. Dauermedikation
- Indikation nicht dokumentiert
- Bei BtM: Chargenpflicht oder Sonderformular fehlt

**Typische Rückläufer / Nachfragen**
- Krankenkasse lehnt wegen fehlender oder nicht plausibler Diagnose ab
- Apotheke: Wirkstärke oder Darreichungsform fehlt
- Rückfrage bei Dauer-BtM: fehlende Verlaufsdokumentation

**Relevante Quellenbereiche**
- G-BA Arzneimittel-Richtlinie (AM-RL)
- KBV Verordnung von Arzneimitteln
- Einheitlicher Bewertungsmaßstab (EBM)
- Bundesmantelvertrag Ärzte (BMV-Ä)

**Häufig übersehene Aspekte**
- Bekannte Dauermedikation und aktuelle Kontrollen können getrennt dokumentiert werden — beides gegebenenfalls festhalten.
- Facharztbefunde werden erwartet, aber die Erwartung wird nicht dokumentiert — gegebenenfalls vermerken.
- Eine eingeschränkte Verordnung erfolgt aus nachvollziehbaren Gründen — diese Gründe gegebenenfalls festhalten.
- Offene Labor- oder Kontrolltermine können für Folgeverordnungen relevant sein und gegebenenfalls vermerkt werden.

## 2. Überweisung

| Bereich | MFA-Fragen | Arzt-Fragen |
|---|---|---|
| **Formale Angaben** | Ist das Überweisungsziel (Fachrichtung / Einrichtung) angegeben? | Ist die Fragestellung für die Überweisung formuliert? |
| | Ist der Überweisungsschein vollständig ausgefüllt? | Sind Fachrichtung und Überweisungsanlass angegeben? |
| | Sind Patientendaten und Datum angegeben? | |
| | Ist eine konkrete Fragestellung für den Facharzt angegeben? | |
| **Entscheidungsgrundlage** | Liegt ein dokumentierter Anlass für die Überweisung vor? | Ist die Indikation für die Überweisung dokumentiert? |
| | Ist die Dringlichkeit erkennbar? | Sind relevante Vorbefunde oder Vorgeschichte angegeben? |
| | | Ist dokumentiert, welche Frage beantwortet oder welche Abklärung erfolgen soll? |
| | | Ist nachvollziehbar, warum die Überweisung erfolgt? |
| **Verlauf und Kontext** | Gibt es frühere Überweisungen in ähnlichem Kontext? | Ist der Verlauf dokumentiert, der zur Überweisung geführt hat? |
| | Gibt es Hinweise auf besondere Rahmenbedingungen? | Gibt es Vorbefunde oder Berichte, die mitgegeben werden sollen? |
| **Weiteres Vorgehen** | Ist dokumentiert, ob Befunde erwartet werden? | Ist dokumentiert, was nach Erhalt des Befunds folgen soll? |
| | Ist ein nächster Schritt oder Wiedervorstellungstermin erkennbar? | |

**Typische Dokumentationsfehler**
- Fragestellung fehlt oder ist zu allgemein
- Dringlichkeit nicht angegeben
- Relevante Vorbefunde nicht erwähnt

**Typische Rückläufer / Nachfragen**
- Facharzt: unklare Fragestellung, fehlende Vorbefunde
- Krankenkasse bei konsiliarischer Überweisung: fehlende Begründung
- Patient: kein Überweisungsschein ausgehändigt

**Relevante Quellenbereiche**
- KBV Überweisung im Vertragsarztrecht
- Einheitlicher Bewertungsmaßstab (EBM)
- Bundesmantelvertrag Ärzte (BMV-Ä)

**Häufig übersehene Aspekte**
- Die Zielrichtung der Überweisung ist der Praxis bekannt — gegebenenfalls ausdrücklich dokumentieren, damit sie für Dritte nachvollziehbar ist.
- Relevante Vorbefunde können mitgedacht und gegebenenfalls im Überweisungsschein oder der Akte vermerkt werden.

## 3. Heilmittelverordnung

| Bereich | MFA-Fragen | Arzt-Fragen |
|---|---|---|
| **Formale Angaben** | Sind Heilmittelart, Frequenz und Verordnungsmenge angegeben? | Sind Heilmittel, Menge und Frequenz erkennbar angegeben? |
| | Sind Diagnosegruppe und ICD-10 erfasst? | Ist die Diagnosegruppe dokumentiert? |
| | Ist der Therapiebeginn angegeben? | Ist erkennbar, ob Erst- oder Folgeverordnung vorliegt? |
| | Ist erkennbar, ob Erst- oder Folgeverordnung? | Ist das Therapieziel nachvollziehbar dokumentiert? |
| | Ist ein Therapieziel angegeben? | |
| | Ist erkennbar, was durch die Therapie erreicht werden soll? | |
| **Entscheidungsgrundlage** | Liegt eine bekannte Indikation für das Heilmittel vor? | Ist die Therapiebegründung aus der Akte nachvollziehbar? |
| | Ist erkennbar, ob eine Vorverordnung vorliegt? | Ist der aktuelle Therapiebedarf erkennbar? |
| **Verlauf und Kontext** | Gibt es Vorverordnungen für dasselbe Heilmittel? | Gibt es Verlaufshinweise, die den Therapiebedarf stützen? |
| | Gibt es Hinweise auf Therapieabbrüche oder Therapieerfolge? | Gibt es Besonderheiten im bisherigen Therapieverlauf? |
| | Wurde bereits eine vergleichbare Therapie durchgeführt? | |
| | Gibt es einen dokumentierten Therapiebericht? | |
| | Liegen Rückmeldungen früherer Behandler vor? | |
| **Weiteres Vorgehen** | Ist dokumentiert, ob ein Kontrolltermin oder eine Verlaufsprüfung geplant ist? | Ist dokumentiert, ab wann und in welchen Abständen der Therapieerfolg geprüft wird? |

**Typische Dokumentationsfehler**
- Falsche oder fehlende Diagnosegruppe
- Erst- vs. Folgeverordnung nicht angegeben
- Therapieziel nicht dokumentiert
- ICD-10 stimmt nicht zur Diagnosegruppe

**Typische Rückläufer / Nachfragen**
- Therapeut: unklare Frequenz oder Verordnungsmenge
- Krankenkasse: fehlendes Therapieziel oder nicht passende Diagnosegruppe
- Genehmigungspflichtige Verordnung: fehlende Begründung

**Relevante Quellenbereiche**
- G-BA Heilmittel-Richtlinie (HeilM-RL)
- KBV Informationen zur Heilmittelverordnung
- Einheitlicher Bewertungsmaßstab (EBM)
- Bundesmantelvertrag Ärzte (BMV-Ä)

**Häufig übersehene Aspekte**
- Das Therapieziel wird in der Praxis oft vorausgesetzt — gegebenenfalls ausdrücklich dokumentieren, damit es für Kostenträger und Therapeuten nachvollziehbar ist.
- Frühere Therapien sind bekannt, aber nicht nachvollziehbar dokumentiert — gegebenenfalls festhalten.
- Therapieberichte liegen vor — gegebenenfalls in der Akte erwähnen oder berücksichtigen.
- Der bisherige Therapieverlauf kann für Folgeverordnungen relevant sein und gegebenenfalls mitgedacht werden.

## 4. Hilfsmittelverordnung

| Bereich | MFA-Fragen | Arzt-Fragen |
|---|---|---|
| **Formale Angaben** | Sind Patientendaten und das Hilfsmittel vollständig angegeben? | Ist das Hilfsmittel konkret benannt? |
| | Ist der ICD-10-Code erfasst? | Ist die Diagnose erfasst? |
| | Ist die Versorgungsart angegeben? z. B. Erstversorgung, Ersatz, Reparatur. | Ist die Versorgungsart dokumentiert? |
| **Entscheidungsgrundlage** | Liegt eine bekannte Indikation für das Hilfsmittel vor? | Ist die Notwendigkeit des Hilfsmittels aus der Akte nachvollziehbar? |
| | Gibt es Hinweise auf frühere Versorgungen? | Ist die Grunderkrankung dokumentiert? |
| **Verlauf und Kontext** | Gibt es Hinweise auf frühere Versorgung oder Ablehnung durch die Krankenkasse? | Ist im Verlauf dokumentiert, warum das Hilfsmittel jetzt erforderlich ist? |
| | Gibt es Hinweise auf veränderten Bedarf oder geänderte Lebensumstände? | |
| **Weiteres Vorgehen** | Ist dokumentiert, ob Kontakt mit Leistungserbringer geplant ist? z. B. Sanitätshaus. | Ist dokumentiert, ob eine Kontrolle des Versorgungserfolgs geplant ist? |

**Typische Dokumentationsfehler**
- Hilfsmittel zu allgemein bezeichnet (kein konkretes Produkt oder Produktgruppe)
- Versorgungsart fehlt
- Grunderkrankung oder ICD-10 nicht dokumentiert
- Bei Genehmigungspflicht: Begründungsschreiben fehlt

**Typische Rückläufer / Nachfragen**
- Krankenkasse: fehlende Notwendigkeitsbegründung
- Sanitätshaus: Verordnung zu unspezifisch
- Krankenkasse lehnt Ersatzversorgung ab mangels dokumentiertem Verschleiß

**Relevante Quellenbereiche**
- G-BA Hilfsmittel-Richtlinie (HilfsM-RL)
- KBV Informationen zur Hilfsmittelverordnung
- Sozialgesetzbuch V (SGB V), §§ 33, 73

**Häufig übersehene Aspekte**
- Frühere Hilfsmittelversorgungen und Ablehnungen durch Kostenträger können für Folgeanträge relevant sein — gegebenenfalls in der Akte festhalten.
- Veränderungen im Alltag oder in der Pflegesituation, die den aktuellen Bedarf begründen, können gegebenenfalls mitdokumentiert werden.

## 5. Krankentransport

| Bereich | MFA-Fragen | Arzt-Fragen |
|---|---|---|
| **Formale Angaben** | Sind Datum, Transportziel und Transportart angegeben? | Ist die Transportart dokumentiert? z. B. Taxi, KTW, RTW. |
| | Sind Patientendaten und Kostenträger erfasst? | Ist die medizinische Notwendigkeit erkennbar angegeben? |
| | Ist erkennbar, ob Einzel- oder Serienfahrten beantragt werden? | |
| **Entscheidungsgrundlage** | Liegt eine bekannte Erkrankung vor, die den Transport begründet? | Ist die Transportnotwendigkeit aus dem Krankheitsbild nachvollziehbar? |
| | Ist die Dringlichkeit oder Transportart erkennbar? | Ist die gewählte Transportart begründbar? |
| **Verlauf und Kontext** | Gab es frühere Transportverordnungen für diesen Patienten? | Gibt es im Verlauf Hinweise, die die Transportnotwendigkeit stützen? |
| | Gibt es Hinweise auf besondere Rahmenbedingungen? z. B. Pflegesituation, Mobilitätseinschränkung. | Gibt es Besonderheiten, die für künftige Fahrten relevant sein könnten? |
| **Weiteres Vorgehen** | Ist dokumentiert, ob Rücktransport oder weiterer Transport erforderlich ist? | Ist dokumentiert, was nach dem Transport folgen soll? |
| | Ist ein nächster Schritt oder Termin erkennbar? | |

**Typische Dokumentationsfehler**
- Transportart nicht angegeben oder nicht begründet
- Serienfahrten ohne Befristungsangabe
- Genehmigungspflichtige Fahrten ohne Antragstellung dokumentiert

**Typische Rückläufer / Nachfragen**
- Krankenkasse: fehlende Begründung der Transportart
- Kostenträger: Serienfahrten ohne Ablaufdatum
- Taxiunternehmen: unvollständiger Transportschein

**Relevante Quellenbereiche**
- G-BA Krankentransport-Richtlinie (KT-RL)
- KBV Informationen zum Krankentransport
- Bundesmantelvertrag Ärzte (BMV-Ä)

**Häufig übersehene Aspekte**
- Transportart und Begründung sind der Praxis bekannt — gegebenenfalls ausdrücklich dokumentieren, damit sie für Kostenträger nachvollziehbar sind.
- Bei Serienfahrten kann die geplante Laufzeit und eine Überprüfung des Bedarfs mitgedacht und gegebenenfalls vermerkt werden.

## 6. Videosprechstunde

| Bereich | MFA-Fragen | Arzt-Fragen |
|---|---|---|
| **Formale Angaben** | Ist dokumentiert, dass der Kontakt per Videosprechstunde erfolgte? | Ist dokumentiert, warum die Videosprechstunde gewählt wurde? |
| | Ist das Anliegen dokumentiert? | Ist dokumentiert, welche Informationen erhoben wurden? |
| **Entscheidungsgrundlage** | Liegt ein bekanntes Anliegen vor, das dokumentiert ist? | Ist die Eignung der Videosprechstunde für das Anliegen aus der Akte nachvollziehbar? |
| | Gibt es Hinweise, dass der Patient für diese Konsultationsform geeignet ist? z. B. bekannter Patient, Folgekontakt. | Ist erkennbar, ob eine körperliche Untersuchung für das Anliegen erforderlich wäre? |
| **Verlauf und Kontext** | Gibt es frühere Videokonsultationen mit ähnlichem Anlass? | Gibt es Verlaufshinweise, die das Anliegen einordnen? |
| | Gibt es Hinweise auf besondere Rahmenbedingungen? z. B. Mobilitätseinschränkung, Pflegebedürftigkeit. | Gibt es Informationen aus früheren Konsultationen, die für das Gespräch relevant sind? |
| **Weiteres Vorgehen** | Ist dokumentiert, ob eine Folgekonsultation geplant ist? | Ist das Ergebnis der Videosprechstunde dokumentiert? |
| | Ist erkennbar, ob Verordnungen, Überweisungen oder sonstige Maßnahmen folgen sollen? | Ist dokumentiert, welche weiteren Schritte vereinbart wurden? |

**Typische Dokumentationsfehler**
- Kontaktform nicht dokumentiert
- Anliegen oder Gesprächsinhalt nicht erfasst
- Ergebnis und Folgeschritte fehlen
- Einwilligung des Patienten nicht aktenkundig

**Typische Rückläufer / Nachfragen**
- KV-Abrechnung: fehlende EBM-Ziffer oder Angaben zur Kontaktform
- Patient: keine Bestätigung des Termins oder Zugangsproblem nicht dokumentiert

**Relevante Quellenbereiche**
- G-BA Beschluss zur Videosprechstunde
- KBV Digitale Versorgung / Videosprechstunde
- Einheitlicher Bewertungsmaßstab (EBM) – Videokonsultationsziffern
- Bundesmantelvertrag Ärzte (BMV-Ä)

**Häufig übersehene Aspekte**
- Kontaktform ist bekannt, aber nicht dokumentiert — gegebenenfalls ausdrücklich festhalten.
- Anlass der Videosprechstunde wird nicht immer nachvollziehbar erfasst — gegebenenfalls begründen.
- Vereinbarte Folgeschritte werden nicht immer in der Akte festgehalten — gegebenenfalls dokumentieren.

## 7. Impfung

| Bereich | MFA-Fragen | Arzt-Fragen |
|---|---|---|
| **Formale Angaben** | Ist der Impfstoff mit Handelsname und Chargennummer erfasst? | Ist der Impfstoff mit Chargennummer und Applikationsort dokumentiert? |
| | Ist das Impfdatum dokumentiert? | Ist erkennbar, welche Impfindikation vorliegt? z. B. Standardimpfung, Reise, Berufsgruppe. |
| | Sind Patientendaten und Kostenträger angegeben? | Ist eine Aufklärung dokumentiert? |
| | Ist erkennbar, ob Erst-, Folge- oder Auffrischimpfung? | |
| | Wurde ein Impfpass vorgelegt? | |
| | Ist der Impfstatus dokumentiert? | |
| **Entscheidungsgrundlage** | Liegt ein bekannter Impfstatus oder Impfausweis vor? | Ist die Impfindikation aus der Akte nachvollziehbar? |
| | Sind Vorerkrankungen oder Allergien in der Akte erkennbar erfasst? | Sind Kontraindikationen oder Vorerkrankungen, die relevant sein könnten, dokumentiert? |
| | | Ist die Aufklärung des Patienten erkennbar? |
| | | Ist dokumentiert, auf welcher Grundlage die Impfempfehlung erfolgt? |
| **Verlauf und Kontext** | Gibt es frühere Impfungen, die dokumentiert sind? | Gibt es Verlaufshinweise, die den Impfzeitpunkt begründen? |
| | Ist der aktuelle Impfstatus erkennbar? | Gibt es Hinweise auf frühere Impfreaktionen? |
| | Gibt es Hinweise auf frühere Impfreaktionen? | Gibt es dokumentierte Gründe für eine Verschiebung oder Ablehnung? |
| **Weiteres Vorgehen** | Ist dokumentiert, ob eine Folgeimpfung oder ein Erinnerungstermin geplant ist? | Ist dokumentiert, ob weitere Impfungen im Rahmen der Grundimmunisierung oder Auffrischung folgen sollen? |
| | Ist erkennbar, ob der Impfausweis aktualisiert wurde? | Ist die Impfung im Impfpass und in der Akte dokumentiert? |

**Typische Dokumentationsfehler**
- Fehlende Chargennummer
- Impfung nicht im Impfausweis eingetragen
- Aufklärung nicht dokumentiert
- Applikationsort fehlt
- Impfindikation nicht erfasst (besonders bei Reise- und Berufsimpfungen)

**Typische Rückläufer / Nachfragen**
- KV: fehlende Chargennummer oder Applikationsort bei Abrechnung
- Krankenkasse: kein Nachweis der Indikation bei Reiseimpfung oder Sonderindikation
- Patient: Impfausweis nicht ausgehändigt oder nicht aktualisiert

**Relevante Quellenbereiche**
- STIKO-Empfehlungen (Robert Koch-Institut)
- G-BA Schutzimpfungs-Richtlinie (SI-RL)
- Einheitlicher Bewertungsmaßstab (EBM) – Impfziffern
- Bundesmantelvertrag Ärzte (BMV-Ä)

**Häufig übersehene Aspekte**
- Impfpass wurde geprüft, aber nicht dokumentiert — gegebenenfalls in der Akte vermerken.
- Impfstatus ist bekannt, aber nicht nachvollziehbar festgehalten — gegebenenfalls ausdrücklich erfassen.
- Impfempfehlung wurde ausgesprochen, ohne die Grundlage zu dokumentieren — beides gegebenenfalls festhalten.

## 8. Wunde

| Bereich | MFA-Fragen | Arzt-Fragen |
|---|---|---|
| **Formale Angaben** | Ist dokumentiert, an welchem Körperteil die Wunde liegt? | Ist die Wundbeschreibung vollständig? z. B. Lokalisation, Größe, Tiefe, Beschaffenheit. |
| | Ist die Wunde beschrieben? z. B. Größe, Aussehen. | Ist das Versorgungsverfahren dokumentiert? |
| | Sind Datum und Uhrzeit der Versorgung dokumentiert? | Ist eine Tetanus-Anamnese erfasst? |
| | Sind verwendete Materialien oder Verbandsmittel erfasst? | |
| | Ist erkennbar, wer die Wundversorgung durchgeführt hat? | |
| **Entscheidungsgrundlage** | Liegt eine bekannte Grunderkrankung vor, die die Wundheilung beeinflussen kann? z. B. Diabetes, Antikoagulation. | Ist die Wundursache aus der Akte nachvollziehbar? |
| | Ist erkennbar, wie die Wunde entstanden ist? | Sind relevante Grunderkrankungen oder Medikamente dokumentiert, die die Heilung beeinflussen können? |
| | | Ist erkennbar, ob ein Tetanusschutz besteht? |
| | | Ist dokumentiert, wie die Wunde entstanden ist? |
| | | Gibt es Hinweise auf Unfallgeschehen? |
| | | Gibt es Hinweise auf Fremdeinwirkung oder Gewalt? |
| | | Ist die Ursache der Wunde nachvollziehbar beschrieben? |
| **Verlauf und Kontext** | Gibt es frühere Dokumentationen dieser Wunde oder ähnlicher Wunden? | Gibt es Verlaufshinweise zur Wundheilung? z. B. Verbandswechsel-Protokolle. |
| | Gibt es Hinweise auf Wundkomplikationen oder -infektionen in der Vorgeschichte? | Gibt es Hinweise auf Chronifizierung oder besondere Heilungsstörungen? |
| **Weiteres Vorgehen** | Ist dokumentiert, ob ein Folgetermin zur Wundkontrolle geplant ist? | Ist dokumentiert, welche Maßnahmen bei Komplikationen eingeleitet werden sollen? |
| | Ist erkennbar, welche Materialien für die weitere Versorgung benötigt werden? | Ist erkennbar, ob eine Überweisung erwogen wurde? z. B. Chirurgie, Wundzentrum. |
| | Ist dokumentiert, wer die weitere Versorgung übernimmt? z. B. Patient, Angehörige, Pflegedienst, Hausarztpraxis, Wundzentrum. | |

**Typische Dokumentationsfehler**
- Keine Tetanus-Anamnese bei verletzungsbedingten Wunden
- Fehlendes Datum oder Uhrzeit der Versorgung
- Verwendete Materialien nicht erfasst
- Wundbeschreibung zu pauschal (z. B. nur „Wunde versorgt")

**Typische Rückläufer / Nachfragen**
- KV-Abrechnung: fehlende Angaben zur EBM-Wundversorgungsziffer (Größe, Verfahren)
- Krankenkasse bei chronischen Wunden: unvollständige Wunddokumentation
- Folgebehandler: fehlende Beschreibung des Ausgangs- oder Verlaufszustands

**Relevante Quellenbereiche**
- Einheitlicher Bewertungsmaßstab (EBM) – Wundversorgungsziffern
- Bundesmantelvertrag Ärzte (BMV-Ä)
- KBV Praxisinformationen Wundversorgung

**Häufig übersehene Aspekte**
- Lage der Wunde am Körper ist bekannt, aber nicht immer beschrieben — gegebenenfalls ausdrücklich dokumentieren.
- Entstehung und Umstände der Wunde können später relevant werden — beides gegebenenfalls festhalten.
- Zusammenhang mit Unfall, Arbeit, Versicherung oder Fremdeinwirkung kann dokumentationsrelevant sein und gegebenenfalls mitgedacht werden.
- Zuständigkeit für die weitere Versorgung gegebenenfalls festhalten, damit nachvollziehbar ist, wer den nächsten Schritt übernimmt.
- Geplante Verlaufskontrollen gegebenenfalls dokumentieren — wann und durch wen.
